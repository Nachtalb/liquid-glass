# liquid-glass.js

Apple-style Liquid Glass for Chromium: SVG displacement filter as `backdrop-filter`.
Live demo: https://liquid-glass.naa.gg

```html
<script type="module" src="liquid-glass.js"></script>
<div data-glass style="border-radius:24px">…</div>
```

`index.html` is the demo (library inlined). Tests: `node liquid-glass.test.mjs`.
